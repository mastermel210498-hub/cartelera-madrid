Política de privacidad

Responsable: María Escobar Lara (carteleramadrid@gmail.com).

Datos que tratamos: esta web no tiene registro de usuarios ni formularios. Si usas «cerca de mí» o «quedar a medio camino», tu ubicación se procesa sólo en tu navegador y no se envía a ningún servidor.

Publicidad: esta web puede mostrar anuncios de Google AdSense. Google y sus socios pueden usar cookies e identificadores para mostrar anuncios, personalizados o no según tu consentimiento, y para medir su rendimiento. Más información en cómo usa Google los datos. Puedes gestionar tu consentimiento en cualquier momento desde el enlace de preferencias de privacidad.

Alojamiento: la web se sirve desde GitHub Pages (GitHub, Inc.), que puede registrar la IP de las visitas por motivos de seguridad.

Derechos: puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a carteleramadrid@gmail.com, y reclamar ante la Agencia Española de Protección de Datos (aepd.es).
